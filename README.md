# bege-proman6
PROMAN6 adalah sistem Enterprise Resource Planning (ERP) mutakhir yang dirancang khusus untuk industri konstruksi dan kontraktor. Sistem ini mengintegrasikan seluruh siklus hidup proyek konstruksi, mulai dari perencanaan anggaran (RAB), pengadaan material (Procurement), manajemen stok, hingga pelaporan progres lapangan secara real-time.
